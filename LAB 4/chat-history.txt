GitHub Copilot: ## 🎮 What the project does

This is a **terminal-based Mastermind game**.

- The computer generates a secret code made of **4 digits**, each from **1–6**.
- The player enters a guess.
- The game reports:
  - **Exact matches**: correct digit in the correct position.
  - **Partial matches**: correct digit in the wrong position.
- The player has **10 turns** to crack the code.
- Enter **q** to quit.
- The game stores guess history and displays the secret code if the player loses.

The entry point is `main.py`, gameplay is in `game.py`, and feedback calculation is in `logic.py`.
